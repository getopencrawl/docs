---
title: Connect Devin Cloud
description: Record new Devin sessions in OpenCrawl and give Devin access to workspace search, skills, and the CLI.
---

## Record Devin sessions

Connect your Devin organization once to make new sessions searchable in your OpenCrawl workspace. OpenCrawl reads them through Devin’s hosted APIs. You can keep using your stock blueprint.

1. As a workspace admin, open **Integrations → Devin → Connect** in OpenCrawl.
2. In the Devin organization you want to record, open **Settings → Devin API → Service users**. Create an organization service user with permission to view organization sessions, then copy its API key.
3. Return to OpenCrawl, enter the key, review what workspace members will be able to search, and select **Connect and record**.
4. Start a new Devin session and give it a task. When the Devin card shows **View indexed session**, open it to see the transcript. You can also search OpenCrawl for a phrase from the conversation.

**Connected** means OpenCrawl accepted the organization credential. The capture status shows when the first session is indexed or when recording needs attention. OpenCrawl records new sessions visible to the credential, including prompts, replies, available tool activity, shell commands and the output excerpts Devin supplies.

To stop recording, open **Integrations → Devin → Manage → Disconnect**. Previously indexed sessions stay in the workspace.

## Use OpenCrawl tools inside Devin

Install the plugin once if you want Devin to search your workspace, resume earlier work, or run the OpenCrawl CLI. It loads in fresh sessions at the scope you choose.

1. Open **Customize → Plugins** in Devin. Choose **Myself** for a personal install or your organization for a team install. Team installs require **Manage plugins** permission.
2. Choose **Add plugin → From repository**. Enter `getopencrawl/opencrawl-plugins` as the repository and `plugins/devin` as the subdirectory. Add the plugin.
3. When indexing finishes, open **Customize → MCPs → opencrawl** and sign in. Each member connects their own OpenCrawl account.
4. Start a new Devin session. Ask it to use the `opencrawl` skill to search for a phrase from a session you’ve shared. The plugin also provides `oc-continue` to resume earlier work and `oc-import-memories` to preview or import your own memories.

## Use the CLI

Ask Devin to run `bin/opencrawl --version` from the installed plugin directory. On stock Ubuntu, the launcher downloads and verifies the matching CLI on first use. For account commands, ask Devin to run `bin/opencrawl login --no-browser` and approve the code in your browser. Check the workspace with `bin/opencrawl whoami`. A fresh VM can use your MCP sign-in while the CLI still needs its own login.
