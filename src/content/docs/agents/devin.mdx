## Record Devin sessions

OpenCrawl records new sessions through Devin’s API. Your stock blueprint works as is.

1. As a workspace admin, open [OpenCrawl Integrations](https://app.getopencrawl.com/integrations) and choose **Devin → Connect**.
2. Follow **Service users in Devin** and choose **Provision service user**. Grant access to view organization sessions and read session events. Copy the token.
3. Paste the token into OpenCrawl and select **Connect and record**. After starting a new session, choose **View indexed session** to see its transcript.

To stop future recording, choose **Manage → Disconnect**.

## Use OpenCrawl tools inside Devin

1. In Devin, open **Customize → Plugins**. Choose **Myself** or your organization, then **Add plugin → From repository**.
2. Enter `getopencrawl/opencrawl-plugins` as the repository and `plugins/devin` as the subdirectory.
3. Once indexed, each member signs in under **Customize → MCPs → opencrawl** and starts a fresh session.

<span id="get-suggestions-during-a-task"></span>
On stock Ubuntu, the plugin automatically looks for relevant workspace history as you work. Devin can cite sources you have permission to read. The same install includes the OpenCrawl skills and CLI.

<span id="use-the-cli"></span>
For authenticated CLI commands, ask Devin to run `bin/opencrawl login --no-browser` from the plugin directory and approve the code.
