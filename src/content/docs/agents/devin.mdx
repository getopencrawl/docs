---
title: Use OpenCrawl in Devin Cloud
description: Install OpenCrawl search, skills, and the CLI on stock Devin Cloud. See what organization recording requires.
---

On a stock Ubuntu blueprint, install the plugin once for your account or team. New Devin sessions load its skills and can search your workspace using your MCP sign-in.

1. Open **Customize → Plugins** in Devin. Choose **Myself** for a personal install or your organization for a team install. Team installs require **Manage plugins** permission.
2. Choose **Add plugin → From repository**. Enter `getopencrawl/opencrawl-plugins` as the repository and `plugins/devin` as the subdirectory. Add the plugin.
3. When indexing finishes, open **Customize → MCPs → opencrawl** and sign in. Each member connects their own OpenCrawl account.
4. Start a new Devin session. Ask it to use the `opencrawl` skill to search for a phrase from a session you’ve shared. The plugin also provides `oc-continue` to resume earlier work and `oc-import-memories` to preview or import your own memories.

## Use the CLI

Ask Devin to run `bin/opencrawl --version` from the installed plugin directory. On stock Ubuntu, the launcher downloads and verifies the matching CLI on first use. For account commands, ask Devin to run `bin/opencrawl login --no-browser` and approve the code in your browser. Check the workspace with `bin/opencrawl whoami`. A fresh VM can use your MCP sign-in while the CLI still needs its own login.

## Record Devin sessions

The repository plugin leaves recording off. In two fresh stock Ubuntu sessions, search worked and neither transcript appeared in OpenCrawl. The administrator enrollment command stopped at `WORKSPACE_IDENTITY_UNAVAILABLE` because the stock snapshot lacked Devin’s OIDC helper.

To record sessions, a workspace admin must prepare and activate an Ubuntu snapshot with the OpenCrawl CLI and Devin’s OIDC helper, connect the Devin organization to the workspace, grant access to session events, and install the generated recording plugin. Verify capture from another OpenCrawl session by searching for the new session’s opening prompt and first command output. [Administrator setup and verification](https://github.com/getopencrawl/opencrawl-core/blob/main/docs/devin-cloud.md#administrator-setup).
