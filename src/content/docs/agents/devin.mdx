---
title: Use OpenCrawl in Devin Cloud
description: Connect Devin to your OpenCrawl workspace for search and CLI access.
---

1. Open **Customize → Plugins** in Devin. Choose **Myself** for a personal install or your organization for a team install. Team installs require **Manage plugins** permission.
2. Choose **Add plugin → From repository**. Enter `getopencrawl/opencrawl-plugins` as the repository and `plugins/devin` as the subdirectory. Add the plugin.
3. When indexing finishes, open **Customize → MCPs → opencrawl** and sign in. Each member connects their own OpenCrawl account.
4. Start a new Devin session and ask it to search OpenCrawl for a phrase from a session you’ve shared.

For CLI commands that need your account, ask Devin to run the bundled CLI with `login --no-browser`, then approve the sign-in in your browser.

Workspace admins can also [set up organization recording](https://github.com/getopencrawl/opencrawl-core/blob/main/docs/devin-cloud.md#administrator-setup).
