title: Connect an agent
description: Set up the coding agents you use on your Mac.
sidebar:

  label: Connect an agent
---

Run `opencrawl setup` and choose your workspace. The Mac setup flow offers Claude Code, Codex, Cursor and Antigravity. Open each selected agent to finish its connection prompts.

If you leave partway through, run `opencrawl setup` again to resume. For a first install, follow [Getting started](/).
