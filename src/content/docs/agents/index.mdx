OpenCrawl publishes native plugins for Claude Code, Codex, Cursor, and Antigravity. Each plugin has builds for macOS (Intel and Apple silicon), Linux (x64 and Arm64), and Windows (x64). [Plugin releases](https://github.com/getopencrawl/opencrawl-plugins/releases).

First-time guided setup is available on macOS. Run `opencrawl setup`, choose your workspace and agents, then open each selected agent to finish connecting.

If you leave partway through, run `opencrawl setup` again to resume. For a first install, follow [Getting started](/).

For Devin Cloud, open **Customize → Plugins → Add plugin → From repository**, enter `getopencrawl/opencrawl-plugins`, and select the subdirectory `plugins/devin`. Connect your account under **Customize → MCPs**, then start a new session. Each member uses their own OpenCrawl login for search. Organization transcript capture is configured separately. [Devin plugin guide](https://github.com/getopencrawl/opencrawl-plugins/tree/main/plugins/devin).
