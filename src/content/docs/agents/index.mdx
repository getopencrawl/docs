OpenCrawl publishes native plugins for Claude Code, Codex, Cursor, and Antigravity. Each plugin has builds for macOS (Intel and Apple silicon), Linux (x64 and Arm64), and Windows (x64). [Plugin releases](https://github.com/getopencrawl/opencrawl-plugins/releases).

First-time guided setup is available on macOS and Linux (x64 or Arm64 with glibc). Run `opencrawl setup`, choose your workspace and agents, then open each selected agent to finish connecting.

If you leave partway through, run `opencrawl setup` again to resume. For a first install, follow [Getting started](/).

For Devin Cloud, install the plugin once for yourself or your organization. Future sessions on a stock blueprint get the CLI, workspace search, and skills. [Use OpenCrawl in Devin Cloud](/agents/devin/)
