---
title: Connect over MCP
description: Give another MCP client access to OpenCrawl search.
---

Add your workspace’s MCP server to the client and sign in. For OpenCrawl Cloud, the server URL is `https://app.getopencrawl.com/mcp`.

For an unattended service, [connect MCP with a Cloud API key](/workspace/api-keys/#connect-an-mcp-client).

Run `test_connection` to check sign-in, then [ask about a past chat](/search/sessions-and-memories/#ask-about-past-chats) your team has shared.
