---
title: Record new Replicas chats
description: Set up ongoing capture for Claude Code and Codex in a shared Replicas environment.
---

![A desk microphone is plugged into a reel-to-reel recorder with tape threaded across its head.](/images/docs/pixel/headers/replicas-capture.png)

Sign in as an OpenCrawl workspace admin. In Replicas, use an account that can edit your team’s environment.

## 1. Open capture setup

In OpenCrawl, open **Integrations** and click **Set up capture** on the Replicas card. The link appears after you start a history import. You can also open [capture setup directly](https://app.getopencrawl.com/agent-setup#replicas-capture). On a self-hosted instance, use **Setup** or **Agent setup** on your own host.

![The Replicas integration card with Set up capture in the lower right.](/images/docs/replicas-capture/integration.jpg)

## 2. Copy the setup prompt

Click **Install on Replicas**. If the browser shows selected text, copy it. The prompt expires in 30 minutes. Click the same button for a fresh one.

## 3. Choose your Replicas environment

In [Replicas](https://app.replicas.dev/), check the organization name in the upper left and open **New workspace**. Choose your team’s environment just above the message box.

![The environment selector is directly above the Replicas message box. In a new organization it reads No environments configured.](/images/docs/replicas-capture/new-workspace.jpg)

If you see **No environments configured**, follow that link and click **New environment**. Keep **Source** set to **Plain**, enter a name, leave **Personal** off, and click **Create**. Return to **New workspace** and select it. [Replicas environment guide](https://docs.replicas.dev/features/environments)

## 4. Send the setup prompt

Paste the prompt into a Claude Code or Codex chat in that environment and send it. Either agent can set up capture for both.

## 5. Check a fresh chat

When setup finishes, start a **new workspace** in the same environment. Send **Reply with “capture check complete”.** Open the chat in OpenCrawl **Sessions** and confirm you can see your message and the reply.

Uploads use the workspace identity. Teammates can use this environment without signing in to OpenCrawl inside Replicas. Recording shares user and assistant messages, including intermediate replies, and tool inputs and outputs with your OpenCrawl team. Human authorship labels are best effort. Incognito is unavailable in Replicas. The organization API key is only needed for [importing retained history](/integrations/replicas/).
