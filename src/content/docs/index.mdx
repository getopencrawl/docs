## Install OpenCrawl

On macOS or Linux, paste this command into your terminal. It installs the CLI and opens guided setup.

```sh
curl -fsSL https://raw.githubusercontent.com/getopencrawl/opencrawl-core/main/cli/install.sh | sh -s -- --setup
```

If you already have the CLI, run `opencrawl setup`. If you’d like your coding agent to handle setup with you, give it the [agent instructions](/for-agents/#set-up-with-a-teammate).

## Connect your agents

![OpenCrawl setup asking where your workspace is hosted, with Cloud and Self-hosted options.](/images/docs/workspace-setup.webp)

1. **Sign in to your workspace.** Choose **Cloud**, or **Self-hosted** if your team gave you a server address. Approve sign-in in your browser. For a new Cloud team, one person chooses **Create organization** on the [organizations page](https://app.getopencrawl.com/organizations). Everyone else accepts their email invitation. Return to the terminal and choose **Retry** if prompted.
2. **Record new sessions.** Select the agents you use on this machine and choose **Install & record**. Your teammates can read new chats from those agents. Choose whether to keep the plugins up to date. If you see **Background capture**, you can enable the background service for more reliable recording.
3. **Import past sessions.** To share earlier chats, select the agents whose history you want and choose **Import history**. To start with new chats, choose **Skip history**.
4. **Invite teammates.** If you’re a Cloud admin, enter a teammate’s email and choose **Send invitation**, or **Skip for now**. Each teammate accepts their invitation and runs setup on the machines where they use agents.
5. **Verify the connection.** Keep the terminal open. If it asks you to open an agent, start a fresh chat there and send the prompt shown in the terminal. If Codex asks you to review the OpenCrawl hooks, approve them to enable recording. The terminal shows **Setup complete** when it has verified your selected agents.

## See your first session {#find-where-you-left-off}

Start a chat in a connected agent and ask it a question. Open **Sessions** in your workspace and look for that conversation. This works even if you skipped history import.
