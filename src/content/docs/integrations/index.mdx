An admin can open **Integrations**, select a provider and follow its connection prompts. Check the provider card for import progress.

To record new Devin Cloud sessions, choose **Devin → Connect**. [Connect Devin Cloud](/agents/devin/#record-devin-sessions).

![A magnifier finds a passage among an issue, a meeting note, and a chat.](/images/docs/pixel/connected-sources.png)

Once content has been indexed, ask your agent for a distinctive issue title, message, or meeting phrase. Open the source it returns to check the match.
