An admin can open **Integrations**, select a provider and follow its connection prompts. Check the provider card for import progress.

![A magnifier finds a passage among an issue, a meeting note, and a chat.](/images/docs/pixel/connected-sources.png)

Once content has been indexed, [search](/search/) for a distinctive issue title, message or meeting phrase and open the matching passage.
