---
title: Replicas
description: Import retained agent chats from a Replicas organization.
---

In Replicas, enable **Team workspace visibility** and create an organization API key. An OpenCrawl admin can enter that key under **Integrations → Replicas** to import the organization’s retained history, including tool calls and results.

You can close the browser while the import runs. Read imported conversations in **Sessions**.

To record future Claude Code and Codex chats, follow [Record new Replicas chats](/agents/replicas-capture/). You can set up recording independently of the history import.
