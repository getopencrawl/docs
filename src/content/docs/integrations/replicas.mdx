---
title: Replicas
description: Sync conversations with a Replicas organization API key and give agents access to OpenCrawl.
---

In Replicas, create an organization API key. An OpenCrawl admin enters it under **Integrations → Replicas → Connect**. OpenCrawl imports retained conversations, including tool calls and results, and periodically checks for new or updated chats. You can close the browser while the sync runs. Read imported conversations in **Sessions**.

The server also uses that key to stream new events from active workspaces. This runs independently of agent setup.

To give Claude Code or Codex access to team tools, copy the agent setup prompt from the same dialog into a Replicas chat. Follow [Set up OpenCrawl agents in Replicas](/agents/replicas/).
