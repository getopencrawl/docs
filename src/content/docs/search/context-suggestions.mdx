---
title: Context suggestions
description: Let a fresh chat pick up a decision your team made earlier.
---

With suggestions enabled, OpenCrawl uses your prompt and recent prompt context to find up to five relevant passages for the agent. You choose which agents receive them.

For Codex, run `opencrawl context-suggestions enable --harness codex`, run `opencrawl setup`, and complete any hook approval. Start a new chat to use it. [Other supported agents and settings](https://github.com/getopencrawl/opencrawl-core/blob/main/cli/docs/context-checks.md).
