title: Context suggestions
description: Choose which agents receive excerpts from earlier work when you send a prompt.
---

![A little robot sprints back with a page of notes for the waiting computer, both boots off the ground.](/images/docs/pixel/headers/context-suggestions.png)

Local agents you choose to record check for relevant past work by default. When you send a prompt, the native plugin sends a shortened, locally redacted version and recent prompt context to your selected workspace. OpenCrawl returns excerpts your agent has permission to read when it finds a match. You can turn off suggestions for a local agent and keep recording. [Capture exclusions](/workspace/privacy/#exclude-a-project-or-session) apply to both.

The [Devin Cloud plugin](/agents/devin/#get-suggestions-during-a-task) checks for suggestions through the signed-in member’s MCP connection. A short opening turn can finish before suggestions arrive.

## Turn suggestions on

Run `opencrawl context-suggestions status` to see which agents check for suggestions. To turn suggestions back on after disabling them, choose one or more agents. This example enables Codex and Claude Code.

```sh
opencrawl context-suggestions enable --harness codex --harness claude-code
opencrawl setup
```

Complete the agent’s hook approval, start a fresh chat, and check your settings with `opencrawl context-suggestions status`. For a self-hosted workspace, use `--api` with your workspace origin.

## When suggestions arrive

| Agent | Delivery |
| --- | --- |
| Codex | At the next safe point in the turn |
| Claude Code | On the next conversation turn |
| Cursor | After a subsequent tool call |
| Antigravity | On a subsequent invocation |
| Devin Cloud (Linux) | In the current turn when Devin calls the member’s suggestions tool |

A suggestion never starts a new turn. Your deployment’s credit policy applies to checks.

## Turn suggestions off

For local agents, run `opencrawl context-suggestions disable --harness codex` for one agent, or `opencrawl context-suggestions disable` for all agents.
