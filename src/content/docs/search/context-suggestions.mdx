---
title: Context suggestions
description: Give an agent relevant excerpts from earlier work as you type a prompt.
---

When you opt in, OpenCrawl sends a shortened, locally redacted prompt and recent prompt context to your selected workspace. It can return up to five passages your agent has permission to read. Recording and suggestions have separate settings. [Capture exclusions](/workspace/privacy/#exclude-a-project-or-session) apply to both.

## Turn suggestions on

With the native plugin installed, choose one or more agents. This example enables Codex and Claude Code.

```sh
opencrawl context-suggestions enable --harness codex --harness claude-code
opencrawl setup
```

Complete the agent’s hook approval, start a fresh chat, and check your settings with `opencrawl context-suggestions status`. For a self-hosted workspace, use `--api` with your workspace origin.

## When suggestions arrive

| Agent | Delivery |
| --- | --- |
| Codex | At the next safe point in the turn |
| Claude Code | On the next conversation turn |
| Cursor | After a subsequent tool call |
| Antigravity | On a subsequent invocation |

A suggestion never starts a new turn. Your deployment’s credit policy applies to checks.

## Turn suggestions off

Run `opencrawl context-suggestions disable --harness codex` for one agent, or `opencrawl context-suggestions disable` for all agents.
