## Search past chats

Ask a connected agent about a decision your team discussed.

> Why did we delay launch? Search our past chats and quote the message where we decided.

Open the matching conversation in **Sessions** to read the full exchange.

## Find a passage

Ask your agent a question using a few words the team actually used, such as a project name or an error message. Narrow the search by repository, date or author when several conversations match.

## Read the surrounding messages

![A highlighted line in a stack of transcripts expands into the matching message with the messages before and after it.](/images/docs/search-context.png)

Ask the agent to fetch the matching passage and quote it. For a session hit, it can also fetch the messages immediately before and after the match. To find a command’s output, explicitly ask it to include tool results.
