---
title: Search and fetch
description: Find the original passage behind a decision, command or conversation.
sidebar:
  order: 1
  label: Search and fetch
---

Ask your agent a question using a few words the team actually used, such as a project name or an error message. Narrow the search by repository, date or author when several conversations match.

Ask the agent to fetch the matching passage and quote it. For a session hit, it can also fetch the messages immediately before and after the match. To find a command’s output, explicitly ask it to include tool results.
