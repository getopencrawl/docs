Open **Sessions** for a chronological transcript. Select a participant to narrow the list, then open a conversation to read its messages and expand tool calls.

Open **Memories** for the latest captured version of a memory file. Its original path helps you identify which file a search result came from.

## Ask about past chats

Ask a connected agent about work your team has shared.

> Why did we delay launch? Find the decision in our past chats and quote the message.

Open the matching conversation in **Sessions** to read the exchange around the quote.
