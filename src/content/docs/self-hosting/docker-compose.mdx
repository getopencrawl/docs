---
title: Docker Compose
description: Run a workspace on a single Docker host.
---

Start with the [single-host installation guide](https://github.com/getopencrawl/opencrawl-core/blob/main/docs/self-host.md). The first run of `./deploy/up.sh` creates the local configuration. Set your workspace URL and run the script again to start the services.

Use the guide’s `--no-airbyte` option for a workspace that only needs agent capture, search and the board.
