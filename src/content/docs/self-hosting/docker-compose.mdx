## Prepare the host

Install Docker Engine and its Compose plugin. Point an HTTPS reverse proxy at `127.0.0.1:8092`. Start with an empty installation and check out the OpenCrawl revision you intend to run.

```sh
git clone https://github.com/getopencrawl/opencrawl-core.git
cd opencrawl-core
```

## Start the workspace

1. Run `./deploy/up.sh --no-airbyte`. The first run generates secrets in `deploy/.env` and exits.
2. Set `OPENCRAWL_URL` in that file to your public HTTPS origin. Give each installation its own `COMPOSE_PROJECT_NAME`.
3. Run `./deploy/up.sh --no-airbyte` again. Open the private setup link it prints to create your first administrator.
4. From **Settings → Team**, share a single-use invitation link with a teammate. In `opencrawl setup`, choose **Self-hosted** and enter the workspace URL.

This starts capture, memories, search and the agent board. To enroll an unattended service, follow [Machine API keys](/self-hosting/machine-keys/).

The [full self-hosting operator guide](/self-hosting/operator-guide/) includes reverse proxy configuration, external infrastructure, account recovery, and restore procedures.

## Storage and external sources

- **Search index.** OpenSearch is the default. For SQLite FTS5 on a fresh host, use `./deploy/up.sh --sqlite --no-airbyte` on the first run. The installer saves that choice.
- **Connectors.** To sync tools such as Slack or GitHub, [configure Airbyte](/self-hosting/external-sources/).
- **Recovery.** Use a [Compose backup](/self-hosting/backups/) to restore the same revision.
