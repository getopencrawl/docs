## Configure Airbyte

Create an API application in your Airbyte instance and choose the workspace OpenCrawl should use. Set these values in `deploy/.env`.

| Setting | Value |
| --- | --- |
| `AIRBYTE_URL` | Airbyte API origin |
| `AIRBYTE_CLIENT_ID`, `AIRBYTE_CLIENT_SECRET` | API application credentials |
| `AIRBYTE_WORKSPACE_ID` | Target Airbyte workspace |
| `OPENCRAWL_AIRBYTE_S3_ENDPOINT` | Private S3 endpoint reachable from connector jobs |
| `OPENCRAWL_AIRBYTE_APP_URL` | OpenCrawl URL reachable from those jobs for credentials. Defaults to the public workspace origin. |

## Connect a source

Set `OPENCRAWL_AIRBYTE_ENABLED=true` and run `./deploy/up.sh` from the repository root. Open **Integrations** in your workspace, choose a [source](/integrations/), and authorize it.
