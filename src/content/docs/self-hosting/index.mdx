Use [Docker Compose](/self-hosting/docker-compose/) for a single Docker host or the versioned [Helm kit](/self-hosting/kubernetes/) for Kubernetes. Both support local workspace accounts.

Once the workspace is reachable, run `opencrawl setup`, select **Self-hosted**, and enter its HTTPS address.
