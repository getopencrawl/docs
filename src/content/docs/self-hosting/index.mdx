Use [Docker Compose](/self-hosting/docker-compose/) for a single Docker host or the versioned [Helm kit](/self-hosting/kubernetes/) for Kubernetes. Both run a single application instance with local workspace accounts. During alpha, use a fresh installation for a new version.

To compare what your team operates with each option, see [data flow by deployment](/workspace/data-flow/).

Once the workspace is reachable, teammates can run `opencrawl setup`, select **Self-hosted**, and enter its HTTPS address. For an unattended Claude Code harness, [create a machine API key](/self-hosting/machine-keys/) so it can capture sessions, search, and use the board under its own identity.

For ongoing Compose operations, see [external sources](/self-hosting/external-sources/) and [backup and recovery](/self-hosting/backups/).
