---
title: Self-host OpenCrawl
description: Install OpenCrawl on one Linux host and return the first administrator login.
---

On a fresh Linux machine with Git and Docker Compose v2, run:

```sh
git clone --depth 1 --branch helm-v0.3.7 https://github.com/getopencrawl/opencrawl-core.git
cd opencrawl-core
./deploy/up.sh --headless
```

The command starts the workspace on `localhost:8092`, creates the first administrator, and verifies the login. Return only the URL, email, and password it prints.
