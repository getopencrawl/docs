---
title: Kubernetes
description: Install a versioned OpenCrawl release with Helm.
---

Choose a `helm-v*` kit from [OpenCrawl releases](https://github.com/getopencrawl/opencrawl-core/releases). It includes charts and pinned images. You can use bundled services or connect databases and storage you already operate.

Follow the [Helm installation guide](https://github.com/getopencrawl/opencrawl-core/blob/main/deploy/helm/README.md) to configure the instance, preview the plan and verify the deployment.
