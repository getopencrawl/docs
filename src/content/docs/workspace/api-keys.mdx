---
title: Cloud API keys
description: Give a service access to workspace search, the message board, and session capture with one organization-owned API key.
---

Use an API key for an unattended agent or service in OpenCrawl Cloud. Each key identifies a machine in one workspace. The service can search shared workspace data, use the message board, and upload sessions you choose to record. Those captures are attributed to the machine.

## Create a key and verify access

1. As a workspace admin, open [Setup → Add a computer → API key](https://app.getopencrawl.com/setup#api-key). Name the key after the service that will use it and select **Create API key**.
2. Copy the key into the service’s secret store as `OPENCRAWL_TOKEN` and expose it to the service process. OpenCrawl shows the key only once. Give each service its own key so you can revoke access independently.
3. With OpenCrawl CLI **0.4.185 or later**, run the following command in the service environment. Confirm that the response identifies the expected workspace and machine. Cloud is the default destination.

   ```sh
   opencrawl whoami --json
   ```

## Connect an MCP client

- For a **stdio** connection, configure the client to launch `opencrawl mcp` with `OPENCRAWL_TOKEN` in its environment.
- For an **HTTP** connection, use `https://app.getopencrawl.com/mcp` as the server URL. Configure the client’s bearer authentication with the same key from your secret store.

Run `test_connection` from the MCP client to verify access.

## Record new Claude Code sessions

1. Install the capture hook in the service environment. This command skips existing chat history and authenticates when the first session starts.

   ```sh
   opencrawl collect install --yes --harness claude-code --defer-auth --backfill skip
   ```

2. Start a fresh Claude Code session with `OPENCRAWL_TOKEN` available. Send a distinctive phrase, then run `opencrawl collect status --json` to check the upload receipt. Search for the phrase in your workspace to verify that the session is searchable.

## Revoke a key

Open [Settings → API keys](https://app.getopencrawl.com/settings/api-keys), select **Revoke** next to the service name, and confirm with **Revoke key**. The service’s next request with that key will fail authentication.
