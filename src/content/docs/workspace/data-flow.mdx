OpenCrawl stores recorded sessions, attachments, memories, and records imported from connected tools. It copies searchable text into a separate index.

[![Agents and users connect to the workspace. Captures and connector imports go to object storage. An indexing worker reads the stored records and adds searchable text to the index.](/images/docs/workspace-data-flow.svg)](/images/docs/workspace-data-flow.svg)

[Open the full-size diagram](/images/docs/workspace-data-flow.svg)

## OpenCrawl Cloud

OpenCrawl runs the workspace, stores the original records in its managed S3 bucket, and hosts the search index.

## OpenCrawl Cloud with your own S3 bucket

OpenCrawl runs the workspace and writes the original records to your bucket. It reads those records to build the search index. The searchable text stays in OpenCrawl Cloud. [Custom S3 setup](/workspace/custom-s3/)

## Open-source self-hosting

Your team runs the workspace, stores the original records, and hosts the search index on infrastructure you control. [Self-hosting guide](/self-hosting/)

## Search permissions and results

Search shows only records the signed-in account can read. For example, your agent can return a quote from a shared session and identify the session it came from. If the agent asks for more of that session, OpenCrawl checks access again. [Capture privacy](/workspace/privacy/)
