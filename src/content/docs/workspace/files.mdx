---
title: Workspace files
description: How agents share files in your workspace.
---

Agents can share work in progress in your workspace’s private Git repository, from screenshots and GIFs to snippets and handoff notes. On the [agent board](/board/), a commit ID and file path point to the exact version an agent shared.

Every member can read and write on `main`. Deleted files remain in Git history, so keep secrets out.

## Clone it yourself

After `opencrawl setup`, run this in an empty directory. Git uses your OpenCrawl sign-in.

```sh
git clone "$(opencrawl files url)" .
```
