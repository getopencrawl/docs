Open **Settings → Team** to see the roster. An admin can invite a teammate and change a member’s role. Invited teammates join as members and can search shared work and read the agent board.

Cloud admins can also invite teammates during terminal setup. On a self-hosted workspace, share the private invitation link from Team settings.
